## 二、审计与整改历史

### 第一阶段：四主题旧分类审计

历史审计曾以四主题结果为基线，发现：

- 预备知识未单独作为主题；
- 集合、逻辑、不等式内容被并入函数；
- 主题五名称不完整；
- 函数应用单元未显式建立；
- 关键词冲突造成三角、立体几何、复数、统计等单元误吸收。

这些问题推动了五主题体系和后续优先级规则的建立，但旧审计中的数字不再适用于当前分类产物。

### 第二阶段：当前规则修正

当前 `classify.py` 已加入并复核以下规则：

| 规则 | 目的 |
|---|---|
| 三角函数优先 | 防止最值、周期、解集等宽泛词误吸收三角题 |
| 立体几何优先 | 防止圆柱、圆锥、截面、体积等题被直线与圆吸收 |
| 复数优先 | 防止复平面、共轭、实部、虚部等题被直线或向量吸收 |
| 统计优先 | 防止统计题中的“排列、选取”等普通词误触发计数原理 |
| 圆锥曲线优先 | 防止椭圆、双曲线、抛物线等强信号被通用关键词覆盖 |
| 概率优先 | 防止概率题中的选取、任选、方案等词触发计数原理 |
| 扩展内容优先 | 矩阵与微积分标注课程标准选修归属，程序框图标注为函数应用中的必修要求，参数方程与极坐标保留混合扩展状态；当前 `out_of_standard` 仅对参数方程与极坐标单元生效 |
| 子串歧义保护 | 处理复数/重复数字、算法/运算法则及 LaTeX 命令冲突 |

## 四、关于答案/解析的核验

上海卷题目源内部统计为：

- 客观题 1700 道，均有 `answer` 块；
- 主观题 561 道，均有 `solution` 块；
- 全部题目共有 2246 个 `solution` 块，少于题目总数的 15 个差异来自客观题不要求独立解析块。

答案与解析覆盖完整性不等于分类语义正确性；解析可作为人工复核证据，但当前分类器仍以题干为正式输入，避免把解答中的辅助方法词引入主分类噪声。

## 五、当前遗留问题

1. 5 道题仅命中“函数”宽泛词，被记录为函数概念与性质兜底，建议作为低置信度样本人工复核。
2. 课程标准选修内容共 67 道：微积分 43、矩阵与变换 24；另有 38 道“参数方程与极坐标”混合单元，其中参数部分对应 B 类选修参变数模型，极坐标尚未在课程标准 PDF 中核定。算法与程序框图 6 道属于必修函数应用中的程序框图要求，不再计入扩展内容。
3. 当前规则产生 19 道主题五候选题；课程标准要求主题五以课题研究形式开展，题目出现频次不能直接与课时占比比较，且这 19 道题仍需逐题确认是否具备建模/探究过程特征。
4. `2019/shanghai_spring.tex` 已有审计记录指出缺少原卷第 19 题；当前统计是已录入题数，不是对原卷全集缺漏的证明。
5. 规则分类已完成结构一致性核验，但尚未用全量人工金标准量化单元级语义准确率。

## 六、结论

当前上海卷分类已经从历史四主题中间结果更新为与课程标准一致的五主题结果：预备知识、函数、几何与代数、概率与统计、数学建模活动与数学探究活动。当前产物覆盖 2261 道已录入题目、未分类为 0，且代码、分类文件、主题正文和 PDF 题量相互一致。

当前分类达到“可复现、可审计、可作为后续人工合理性审查基线”的状态；不应把零未分类解读为零语义误分类，也不应把已录入题数解读为原卷全集完整覆盖。主题五的 19 道记录和扩展内容的课标范围仍需按上述口径进一步人工复核。
