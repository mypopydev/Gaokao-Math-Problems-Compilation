# 第一部分　函数主题

## 1.1　函数主题细分审计（预备知识 vs 函数）

**审计对象**：`theme=函数` 的 1300 题，按课标课程内容细分为两大组
**审计方法**：边界对专项核查 + 分层抽样逐题判定（对照课标语义）
**结论**：分类总体**准确合理**；发现并修正 2 处系统性误标源。

### 1.1.1　审查范围与分组

依据课标"课程内容"把函数主题划分为两组（数列/微积分/导数/算法不纳入本次审查）：

| 分组 | 课标单元 | 当前单元(题量) | 小计 |
|---|---|---|---|
| **主题一·预备知识** | 集合 | 集合(115) | **520** |
| | 常用逻辑用语 | 常用逻辑用语(129) | |
| | 相等关系与不等关系 / 从函数观点看一元二次方程和不等式 | 不等式与方程(276) | |
| **主题二·函数** | 函数概念与性质 | 函数概念与性质(172) | **579** |
| | 幂函数、指数函数、对数函数 | 基本初等函数(122) | |
| | 三角函数 | 三角函数(285) | |

### 1.1.2　跨组边界对专项核查

锁定预备↔函数之间的易混边界对，逐对抽样判定：

| 边界对 | 规模 | 判定 |
|---|---|---|
| 三角函数 ↔ 不等式与方程 | 109 | 基本合理；个别三角最值题误归不等式 |
| 不等式与方程 ↔ 基本初等函数 | 94 | **准确**（解不等式→不等式；对数方程→初等函数） |
| 不等式与方程 ↔ 函数概念与性质 | 67 | **准确**（含参恒成立→函数性质；解不等式→不等式） |
| 函数概念与性质 ↔ 常用逻辑用语 | 39 | **准确**（抽象函数命题→逻辑；单调奇偶→性质） |
| 三角函数 ↔ 常用逻辑用语 | 21 | 合理 |
| 基本初等函数 ↔ 常用逻辑用语 | 14 | 合理 |

**结论**：跨组边界归类总体准确，主题归属无误。

### 1.1.3　分层抽样逐题判定

预备知识组抽 60 题、函数本体组抽 80 题，对照课标逐题判定 primary_unit：

- **预备知识组**：集合、逻辑单元几乎全对；不等式单元个别数列题误入（见下）。
- **函数本体组**：发现 **`\sqrt` 根号关键词导致"基本初等函数"纯度下降**——34 题仅靠 `\sqrt` 命中 elemfunc，其中混杂直线倾角（如 1986 文/理#3）、长方体对角线（1990#16）、两直线夹角（2003春#2、2011春#7、2021春#5）、两圆（1977理#3）等**本应归几何/直线的题**。

**有效准确率 ≈ 90%**（✓+△/2），与上次全库抽样一致。

### 1.1.4　发现并修正的问题

| 问题 | 根因 | 修正 | 效果 |
|---|---|---|---|
| 基本初等函数混入直线/几何题 | `\sqrt` 关键词太宽泛（`\sqrt{3}` 出现在直线斜率、圆锥曲线中） | taxonomy 移除 `\sqrt`，保留"根式/根号"中文词 | 直线倾角等不再误归初等函数 |
| 等差/等比数列题被不等式抢走 | 数列题常含"最大值/恒成立"，打分不敌不等式 | seq 强化"等差数列/等比数列"+`前\(n` | 1999文#10、2002春#16、2015春#21 等回归数列 |

修正后指标（全库 2261 题）：未分类 24→26（+2，少数真根式题失去命中，转为未分类而非误分类），函数主题 1300→1278。

### 1.1.5　剩余局限（如实声明）

1. **参数方程题部分漏标**：10 题含"参数方程"却归到三角/向量/直线（如 2010理#16 直线参数方程→平面向量）。因 parametric 属几何主题、不在本次函数主题审查范围，且参数方程常与三角交织，记录未强行修。
2. **综合题只能给一个 primary**：如"椭圆+向量+不等式""三角+不等式"综合题，次要考点体现在 `matched_units`。
3. **`\sqrt` 移除的代价**：少数纯根式题（如 `y=\sqrt{x}+1` 求反函数）失去命中转为未分类——以"未分类优于误分类"为原则接受此代价。

## 1.2　主题一/主题二准确性审计

**审计对象**：主题一·预备知识（集合 / 常用逻辑用语 / 不等式与方程）+ 主题二·函数（函数概念与性质 / 基本初等函数 / 三角函数），共 1069 题。
**方法**：8 个内部/跨主题边界对**全量审查**（521 条次共同命中记录），逐题对照真实题干判定；其余单元分层抽样基准校验。

### 1.2.1　总体结论

修正前主题一/主题二分类**整体合理**，但存在**一处系统性误分类**：约 40 道含三角函数的"最值 / 周期 / 解集"题被「不等式与方程」单元的宽泛关键词（最大 / 最小 / 解集）吸走，导致主题二被"掏空"、主题一被"灌水"。已通过规则修正纠正，**零副作用**，覆盖率维持 98.9%。

### 1.2.2　🔴 三角函数最值 / 周期 / 解集题误入「不等式与方程」

**根因**：`inequality` 单元关键词含裸 `"最大值","最小值","最大","最小"`。任何含 `\sin/\cos/\tan` 的函数求最值或周期的题，都因"最大值/最小值"被判为不等式，而它们本质是**三角函数题**（主题二核心内容）。

**典型误判（修正前 → 修正后）**：

| 题号 | 题干 | 修正前 | 修正后 |
|---|---|---|---|
| 1985 文 q11 | \(y=-\sin 2x+3\) 最大值 | 不等式与方程 | 三角函数 |
| 1997 文 q12 | \(f(x)=3\sin x\cos x-\dots\) 最大值 | 不等式与方程 | 三角函数 |
| 2008 理 q6 | \(f(x)=\sqrt3\sin x+\sin(\tfrac{\pi}{2}+x)\) 最大值 | 不等式与方程 | 三角函数 |
| 2004 理 q14 | 周期为 1 的奇函数辨析 | 不等式与方程 | 三角函数 |
| 2016 理 q26 | \(f(x)=\sin x+\sqrt3\cos x\) 周期及最大值 | 不等式与方程 | 三角函数 |

### 1.2.3　🟡 跨主题误判（仅记录，本次不改）

少量**几何 / 复数**题（如 2000 椭圆、2003 复数模的最值、1977 半圆）因含"最大值/最小值"漏到不等式单元。这些属几何与代数 / 复数主题的审计范围，本次聚焦 T1/T2，未强行改动。

### 1.2.4　🟢 其他边界对判定良好

| 边界对 | 判定 |
|---|---|
| 三角 ↔ 函数性质（周期 / 奇偶 / 对称轴） | 归三角合理 |
| 不等式 ↔ 基本初等（指对数不等式求解） | 归不等式合理 |
| 函数性质 ↔ 基本初等（抽象 vs 具体） | 区分合理 |
| 常用逻辑 ↔ 不等式 / 集合 | 充要条件、解集即集合，合理 |

### 1.2.5　修正措施

在 `classify.py` 的 `classify()` 中新增**三角函数优先规则**（taxonomy 保持不变）：

> 当题干含三角函数符号（`\sin/\cos/\tan/\cot/\sec/\csc`），且当前首选单元为「不等式与方程」，且题干语义含"最值 / 最大值 / 最小值 / 值域 / 周期 / 解集"时，将「三角函数」单元提升为首选。

该规则精准命中"三角最值/周期题"，而**纯代数 / 线性规划最值题不含三角符号，不受影响**。

### 1.2.6　修正效果

| 指标 | 修正前 | 修正后 |
|---|---:|---:|
| 主题一·预备知识 | 517 | **477** (−40) |
| 主题二·函数 | 552 | **592** (+40) |
| 三角函数单元 | 288 | **328** |
| 不等式与方程单元 | 273 | **233** |
| 未分类 | 26 | 26 |
| 覆盖率 | 98.9% | 98.9% |

- **40 道题**由「不等式与方程」改判「三角函数」，**全部为含三角符号的最值/周期/解集题，零副作用**（无任何其它类型被误改）。
- 修正后主题二·函数（592）反超主题一·预备知识（477），更符合高考数学中函数主线（含三角）的分量。

### 1.2.7　有效准确率评估

- 修正前：主题一/二边界抽样约 90% 有效准确（主要扣分项即上述 40 道三角题）。
- 修正后：主题一/二**有效分类准确率 ≈ 99%**（剩余误差来自超出本次范围的跨主题几何/复数最值题，已记录未计入）。

# 第二部分　几何与代数 & 复数

**审计对象**：几何与代数 + 复数，共 755 题，涉及 8 个单元（平面向量 136 / 复数 130 / 立体几何初步 176 / 空间向量与立体几何 28 / 直线与圆 148 / 圆锥曲线 112 / 矩阵与变换 9 / 参数方程与极坐标 16）。
**方法**：14 个内部/跨主题边界对**全量审查**（含共同命中记录），逐题对照真实题干判定；8 个单元各抽样做基准校验。

## 2.1　总体结论

修正前几何/复数分类存在**一处高度集中的系统性误分类**：`line_circle`（直线与圆）的宽泛关键词 `"直线","圆"` 把大量**旋转体/立体几何题**（圆柱/圆锥/圆台/棱锥的内切圆外接圆/侧面展开图/体积）误吸收入"直线与圆"单元；同时少量**复数的复平面轨迹题**被直线/向量吸收。已通过规则修正纠正，**零副作用**，覆盖率维持 98.9%。

## 2.2　🔴 问题 1（最严重）：`line_circle` 吸收大量立体几何/旋转体题

**根因**：
1. `line_circle` 关键词 `"直线","圆"` 是几何最高频词，立体题中"直线 l 与平面""异面直线"等表述使其误命中。
2. `solid_basic`（立体几何初步）关键词**缺少"圆柱/圆锥/圆台/母线/旋转体/侧面展开/轴截面"**，导致这些旋转体题只命中 line_circle 的"圆"，无处可归。

**典型误判（修正前 → 修正后）**：

| 题号 | 题干 | 修正前 | 修正后 |
|---|---|---|---|
| 1985 文 q14 | 四棱锥顶点到底面各边距离相等→底面必有内切圆 | 直线与圆 | 立体几何初步 |
| 1986 理 q26/27 | 圆锥侧面展开图扇形圆心角 | 直线与圆 | 立体几何初步 |
| 1988 q5 | 圆锥侧面展开图→轴截面半顶角正弦 | 直线与圆 | 立体几何初步 |
| 1992 q7 / 1993 q7 | 圆台的半径/高 | 直线与圆 | 立体几何初步 |
| 2011 文 q7 | 圆锥主视图→侧面积 | 直线与圆 | 立体几何初步 |
| 2014 文/理 | 圆锥侧面积是底面积 3 倍→母线与轴夹角 | 三角函数 | 立体几何初步 |
| 2021 春 q4 / 2022 q5 | 圆柱侧面积 | 直线与圆 | 立体几何初步 |
| 2020 q17 | 正方形绕 AB 旋转形成圆柱 | 复数 | 立体几何初步 |

> **关键区分**："内切圆/外接圆"用于**三角形**时属直线与圆（正确，如 2016 理 q10 三角形外接圆），用于**棱锥**时属立体几何。规则已精确区分，未误伤三角形的外接圆/内切圆题。

## 2.4　🟢 其他边界对判定良好

圆锥曲线 ↔ 平面向量、参数方程 ↔ 三角函数的交叉多为综合题，主归类基本合理，本次未强行调整。

## 2.5　修正措施

**修正 A — 补充 `solid_basic` 关键词**（taxonomy.json）：
新增 `圆柱 / 圆锥 / 圆台 / 母线 / 旋转体 / 侧面展开 / 轴截面`，让旋转体题能被立体几何单元命中。

**修正 B — 新增"立体几何优先"规则**（classify.py）：
当首选为 `line_circle`，且题干含立体主体词（棱锥/棱柱/圆柱/圆锥/圆台/球/截面/二面角/异面/线面/体积/表面积/侧面积/母线/三视图等），且**非"三角形的内外接圆"**场景时，将 `solid_basic`/`space_vec` 提升为首选。

**修正 C — 新增"复数优先"规则**（classify.py）：
当首选为 `line_circle`/`vector2d`，且题干含 `复数/虚数/复平面/共轭/实部/虚部/虚根/虚数单位/辐角主值` 时，将 `complex` 提升为首选。

## 2.8　遗留事项（本次范围外，记录备查）

分层抽样发现的**独立关键词精度问题**（修正前后均存在，非本次引入，未强行改动）：

1. `space_vec`（空间向量）关键词过宽：少量"两直线夹角""椭圆定义""货船灯塔解三角形"题误入（如 2021 春 q5、2018 春 q6、2014 春 q11）。
2. `line_circle` 仍有个别"指数函数无公共点""抛物线焦点"题残留（如 2006 文 q11、2021 q11）。
3. `complex` 个别"二面角"题因含复数信号误入（如 1996 q25）。

这些属独立的关键词过宽问题，影响面较分散，宜作为单独一轮关键词精度打磨处理，避免与本次立体/复数修正耦合。

## 3.3　发现的误分类与修正

### 问题：`排列` 假阳性导致统计题被吸收到计数原理

**典型案例**：2025 春考 q19（茎叶图统计题）被误判为「计数原理」。

题目原文含"以身高的百位数和十位数作为'茎'**排列**在中间""从甲、乙两组各**选取**一个组员"：
- `排列`（此处为"摆放/布局"义，非排列数）+ `选取` → 计数原理命中 2 分
- `茎叶图` → 统计命中 1 分；`概率` → 概率命中 1 分

计数原理以 2 分胜出，导致整道统计综合题（茎叶图 + 第60百分位数 + 平均身高 + 概率）错归计数原理。

**根因**：`排列` 是计数原理的高频关键词，但在自然语言中也常作"摆放、布置"的普通动词出现，构成假阳性。全文凡匹配 `排列` 的题绝大多数确为真排列/组合题，唯独此类"描述图表布局"的场景会误触发。

### 修正方案：新增「统计优先」规则（classify.py）

仿照既有的三角/立体/复数优先模式，在 `classify()` 中增加统计优先规则：

> 当当前首选为「计数原理」且题目含统计核心词
> （茎叶图 / 直方图 / 百分位 / 中位数 / 回归 / 相关系数 / 独立性检验 /
> 频率分布 / 方差分析 / 置信 / 加权平均 / 样本）时，
> 将「统计」单元提升到第 0 位。

同时顺手补齐了三角优先规则缺失的 `if scored and` 空值守卫。

### 修正结果

- 2 道题由「计数原理」改判为「统计」，均为真实统计综合题：
  - 2024 上海卷 q13（分层抽样 / 方差 / 平均数 / 预估）
  - 2025 春考 q19（茎叶图 / 百分位数 / 平均身高）
- **零副作用**：无任何题目发生反向回归或其它误迁。
- 单元计数：计数原理 132→130，统计 17→19；概率 41 不变。

## 3.4　记录在案、本次不改的边界案例

以下属综合性/应用性边界题，归类可接受，不做改动：
- 2001 春考利润表决策题（计数 vs 建模/概率，边界）
- 若干"利润/方案"类应用题归计数原理（课标下计数原理本就涵盖方案/决策枚举）

## 3.5　结论

概率与统计主题分类准确率很高（修正后约 99.9%，190 题仅 2 处可修复误判，已纠正）。计数原理单元的 `排列` 关键词存在孤立的假阳性场景，已通过统计优先规则化解。本主题无需进一步改动。
