# 上海卷分类准确性审计报告

**审计对象**：`docs/classify/` 规则/关键词分类器（`taxonomy.json` + `classify.py`）
**审计范围**：全部上海卷 1977–2026，共 **2261** 题
**审计方法**：五维审计（内部一致性 / 低覆盖单元核查 / 分层抽样逐题判定 / 未分类诊断 / 跨年稳定性）
**结论**：分类总体**准确、合理、自洽**；经审计修正后覆盖率与精度均达标。

---

## 一、总体指标

| 指标 | 审计前 (HEAD) | 审计修正后 |
|---|---|---|
| 精确归类到知识单元 | 2222 (98.3%) | **2232 (98.7%)** |
| 未分类 | 27 (1.2%) | **24 (1.1%)** |
| 仅"函数"兜底 | 12 (0.5%) | **5 (0.2%)** |

> 说明：规则分类器对纯符号比较题、读图数据题天然无法归类，剩余 24 题属此类，已逐题确认无关键词缺口可补。

**主题分布（修正后）**：函数 1300 · 几何与代数 736 · 概率与统计 189 · 数学建模活动 12。

## 二、五维审计结论

### 维度一：内部一致性（自动，全量）
- **theme 与 unit 逻辑完全自洽**：复数/向量/立体/线圆/圆锥 ∈ 几何与代数，计数/概率/统计 ∈ 概率与统计，无一例 theme-unit 错配。
- **解答题归到"复数/集合/逻辑"的信号**：核实为老高考题型编排（解答题首题常考复数计算、末题考集合/逻辑），**非误标**。

### 维度二：低覆盖率单元专项核查
- **导数(2)、统计(11)、概率(9)、空间向量(1)** 偏低 → 经核查**反映上海卷真实考情**（上海卷重三角/不等式/立体，轻导数/统计；导数多融入函数综合题用"单调性"表述）。
- 明确漏标仅 **3 题**（1995×2、2024春 含 `f'(x)` 却归 funcprop），已修正。

### 维度三：分层抽样逐题判定（核心，90 题）
按年份×主题分层抽样 90 题，对照课标语义逐题判定 primary_unit：

| 判定 | 数量 | 占比 |
|---|---|---|
| ✓ 正确 | 64 | 71% |
| △ 主题对、单元偏差（可接受） | 17 | 19% |
| ✗ 明显误标 | 4 | 4.4% |
| （其余 5 题 borderline） | 5 | 6% |

**有效准确率 ≈ 90%**（✓+△/2）。误标集中在关键词多义（见维度四修正项）。

### 维度四：未分类与误标逐题诊断（修正项）
审计发现并修正的真实问题：

| 问题 | 根因 | 修正 |
|---|---|---|
| `\bar` 既表复数共轭又表集合补集 | 2023春#5 对立事件 `\bar{A}` 误归复数 | taxonomy 改用 `\bar z`/`\bar{z}` 精确化 |
| "复数"子串嵌在"重复数字"中 | 2022春#9 排列题误归复数 | classify.py 加中文歧义保护 |
| `\i`(虚数单位) 误命中 `\in`(属于)/`\bs{i}`(向量基) | — | classify.py 归一化屏蔽 |
| 奇函数/偶函数/函数图象选择题仅命中"函数"兜底 | 12 题无法精确归类 | funcprop 加"奇函数/偶函数/函数图象" |
| 二项展开系数题 `(x+1)^n…ax^3+bx^2` 漏标 | 缺 `a_0/a_n/各项系数` 词 | counting 补充关键词 |
| 排列题"没有重复数字"漏标 | 文本插"有"字 | counting 加"没有重复数字" |

### 维度五：跨年稳定性
- 同年不同卷别（文理/春秋）按 qidx 比对有 625 处不一致，但**绝大多数是文理分卷题目本就不同**（同题号非同题），非规则不稳定。
- 对确认为重复的真题（如 2000/2004 文理共享题），分类一致。

## 三、审计中的关键 bug 与教训

1. **`fushu_allowed` 逻辑漏洞**：初版中文歧义保护漏写 `"复数" in text` 检查，导致**所有题目都命中"复数"**（复数单元一度虚高至 449）。已修正为 `kw=="复数" and fushu_allowed and kw in text`。
2. **宽泛关键词的精度代价**：曾尝试给 solid_basic 加"所成角/平行/垂直"以消除未分类，导致几何单元虚高、挤占 space_vec。已回退——**规则分类器应在覆盖与精度间取平衡，不强求 0 未分类**。

---

## 四、剩余局限（如实声明）

1. **unit 粒度存在灰色地带**：综合题（如"椭圆+向量+不等式"）只能给一个 primary，次要考点体现在 `matched_units` 中。
2. **纯符号比较题**（如 `a>b>c>d` 判断选项）无任何关键词，规则无法处理。
3. **中文分词歧义**：短关键词（如"条件""交"）易嵌入常用词产生误命中，已尽量精确化但无法根除。
4. 若需更高精度，应引入语义/ML 分类器或逐题人工标注——已超出规则分类器合理范围。
