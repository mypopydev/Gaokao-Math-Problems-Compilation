# 分类正确性第二轮审计与整改方案

**审计日期**: 2026-08-31
**审计对象**: `docs/classify/classification.json`（上海卷 2261 题，25 个单元，0 未分类）
**对照标准**: 《普通高中数学课程标准（2017 年版 2025 年修订）》
**审计性质**: 先调查、后方案；本轮**未修改**任何分类结果

## 一、审计方法

| 检查 | 做法 | 结果 |
|------|------|------|
| A 分布统计 | 22 单元 / 5 主题 / 3 模块的题数分布 | 见 §2.1 |
| B 强信号冲突 | 为每个单元定义"强信号关键词"（如 `椭圆`/`焦点` → 圆锥曲线），找出**归入 A 单元但 A 无强信号、B 单元有**的题 | **194 题（8.6%）** |
| C 文/理同题一致性 | 同年文理卷相似度 ≥ 0.90 的题配对（difflib），比对分类是否一致 | 274 对，**仅 1 处不一致（0.4%）** |
| D 关键词宽度体检 | 统计各单元"无强信号支撑"比例；反向扫描低召回（含"概率"却非 prob 等） | 见 §2.2 |

**关键结论：分类器本身是稳定的**——文/理近重复题 274 对只有 1 处不一致，说明打分确定、无随机噪声。
因此所有问题都是**系统性偏差**：一处规则修正可批量修复数十道题，但也会批量引入新偏差，必须逐簇抽样确认后再落地。

## 三、六个系统性偏差

### ① 圆锥曲线被"直线与圆"整片吞掉（最严重，127 题）

**根因**：`line_circle` 的关键词 `圆` 是 `椭圆`/`圆锥曲线` 的**子串**，每道椭圆题都自动给"直线与圆"加 1 分；再叠加平局时按 `taxonomy.units` 顺序决胜（`line_circle` 索引 13 < `conic` 索引 14），`conic` 永远输。

**证据**（强信号冲突簇）：

| 现分类 → 应为 | 题数 |
|---|---:|
| line_circle → conic | 19 |
| vector2d → conic | 11 |
| inequality → conic | 15 |
| logic → conic | 10 |
| trig → conic | 10 |
| solid_basic → conic | 8 |
| seq → conic | 4 |

**典型样例**：

- 1988 上海#9「到椭圆 $x^2/25+y^2/9=1$ 右焦点的距离与直线 $x=6$ 的距离相等的点的轨迹方程」→ 现：直线与圆
- 2020 上海#10「椭圆 $C:x^2/4+y^2/3=1$ 的右焦点为 $F$，直线 $l$ 过 $F$ 交椭圆于 $P$、$Q$」→ 现：直线与圆
- 2019 上海#20「椭圆 $x^2/8+y^2/4=1$，$F_1$、$F_2$ 为左右焦点，直线 $l$ 过 $F_2$ 交椭圆于 $A$、$B$」→ 现：直线与圆
- 2023 上海#20「抛物线 $\Gamma:y^2=4x$，点 $A$ 到准线的距离为 3」→ 现：平面向量

**边界反例（需保护）**：2015 上海春#20「在复平面上，满足 $|z-1|=|z+\mathrm{i}|$ 的复数 $z$ 对应点的轨迹」，选项含"椭圆/圆/线段/直线"，若按 conic 优先会被误判为圆锥曲线——实为**复数**。故规则须带"复数语境不让位"保护。

---

### ② 概率题被"计数原理"抢走（39 题）

**根因**：`counting` 有 36 个关键词，含 `选取`/`任选`/`抽取`/`方案`/`情况有`；概率题几乎必带这些词，而 `prob` 仅 13 个关键词。现有"统计优先"规则只处理 `counting → stat`，**没有 `prob` 的对应规则**。

**证据**：全文搜索含"概率"却未归入 `prob` 的题共 **39 道**，其中 counting 21、set 6、vector2d 5、logic 1。

**典型样例**：

- 2019 上海#10「三位数密码锁，每位在 $0\sim9$ 中选取，恰有两位数字相同的概率」→ 现：计数原理
- 2023 上海春#10「4 男 6 女，从 10 人中任选 3 人，恰有 1 男 2 女的概率」→ 现：计数原理
- 1994 上海文/理#18「9 支足球队中 5 支亚洲队 4 支非洲队，任意抽取两队，1 亚 1 非的概率」→ 现：计数原理
- 2018 上海#9「5 个砝码中随机选取 3 个，总质量为 9 克的概率」→ 现：计数原理

---

### ③ 非课标内容漏标（影响 △非课标 标注）

**证据**：`parametric`（参数方程与极坐标）现仅 16 题，实际至少 38 题。

| 方向 | 题数 |
|---|---:|
| trig → parametric | 11 |
| line_circle → parametric | 5 |
| conic → parametric | 4 |
| inequality / set / trig → matrix | 12 |
| elemfunc → algorithm | 1 |

**典型样例**：

- 1989 上海#20「下列参数方程（$t$ 是参数）中与 $y^2=x$ 表示同一曲线的是」→ 现：三角函数（因选项含 $\sin t/\cos t$）
- 1986 上海理#7「极坐标方程 $\rho=\dfrac{5}{2-4\cos\theta}$ 所表示的曲线是」→ 现：圆锥曲线（因选项含"椭圆/抛物线/双曲线"）
- 2011 上海文#11「行列式 $\begin{vmatrix}a&b\\c&d\end{vmatrix}$ 所有可能值中最大的是」→ 现：相等关系与不等关系

⚠️ **重要例外 —— `极限` 不能算非课标**：30 道"无穷等比数列各项和 / 数列极限"题（如 1991 上海#6、1999 上海文#18）在课标体系中属**数列语境**，若按 `极限` 归入"微积分（选修）"，会把 30 题错标为 △非课标。故 R3 的触发词表**排除 `极限`**。

---

### ④ 空间向量与立体几何过度捕获（27 题中 22 题）

**根因**：`space_vec` 关键词为 `空间向量/二面角/线面角/法向量/夹角/距离/空间直角坐标系`，其中 `夹角`、`距离` 过宽，任何平面解析几何题、解三角形题都会命中。

**典型样例**（22 题全部为平面问题）：

- 1985 上海理#3「点 $(0,1)$ 到直线 $x+y=2$ 的距离」→ 现：空间向量与立体几何（应为 直线与圆）
- 2003 上海春#2「直线 $y=1$ 与 $y=\sqrt3x+3$ 的夹角」→ 现：空间向量与立体几何（应为 直线与圆）
- 2011 上海文#8「$\angle CAB=75^\circ$，$\angle CBA=60^\circ$，求 $AC$ 距离」→ 现：空间向量与立体几何（应为 三角函数）
- 2010 上海文#8「动点 $P$ 到点 $F(2,0)$ 的距离与到直线 $x+2=0$ 的距离相等，求轨迹方程」→ 现：空间向量与立体几何（应为 圆锥曲线）

---

### ⑤ 相等关系与不等关系过度捕获（237 题中 140 题）

**根因**：`inequality` 关键词含 `最大值/最小值/最大/最小/比较/解集/方程组/约束`，均为跨领域通用词，在"求最值"类题目中横扫其他单元。

**冲突去向**：→ conic 15、→ vector2d 8、→ trig 9、→ seq 7、→ funcprop 7、→ matrix 7、→ solid_basic 6、→ stat 3。

**典型样例**：

- 2015 上海理#5「抛物线 $y^2=2px$ 上的动点 $Q$ 到焦点距离的最小值为 1」→ 现：相等关系与不等关系（应为 圆锥曲线）
- 2016 上海文#14「无穷数列 $\{a_n\}$，若对任意 $n$ 有 $S_n\in\{2,3\}$，则 $k$ 的最大值」→ 现：相等关系与不等关系（应为 数列）
- 2015 上海理#5「线性方程组的增广矩阵为 $\begin{pmatrix}2&3&c_1\\0&1&c_2\end{pmatrix}$」→ 现：相等关系与不等关系（应为 矩阵与变换）

⚠️ 这一簇**不能简单删关键词**：模拟显示删掉 `最大值/最小值/最大/最小/比较` 会产生 **22 道新的未分类题**，且 132 题改判去向分散（funcprop 24、vector2d 10、trig 9、seq 9…），需按"让位规则"而非"删除"处理。

---

### ⑥ 常用逻辑用语过度捕获（127 题中 57 题，需谨慎）

**根因**：`logic` 关键词含 `命题`、`条件`，而"下列命题中正确的是/假命题是"是**选择题干套话**，与常用逻辑用语无关。

**典型误判**：

- 1986 上海文#5「在空间，下列命题中正确的是……」（实为立体几何）
- 1995 上海文#8「下列四个命题中的真命题是……」（实为直线与圆）
- 2002 上海理#16「家庭用电量与气温关系，以下叙述正确的是」（实为数学建模，图（1）图（2）读图）

⚠️ **但充要条件题本身确实属于常用逻辑用语**，不能一并砍掉：

- 2016 上海春#21「"$f(0)=0$"是"$y=f(x)$ 为奇函数"的（  ）」→ logic **正确**
- 2014 上海春#23「"$F(a,b)=0$"是"点 $P$ 在曲线 $C$ 上"的（  ）」→ logic **正确**

模拟验证：只删 `条件` → 21 题改判，但去向有好有坏（2001 上海文#21"洗蔬菜残留农药"logic→inequality 反而更差）；只删 `命题` → 28 题改判且产生 3 道未分类。**结论：本簇风险高于收益，留待阶段三。**

## 四、整改方案

### 阶段 0（建议先做）：建立金标准抽样集

按年份分层抽样 **120 题**（覆盖 1977–2026、文/理/春/秋、各主题），人工标注正确单元，落为 `docs/classify/golden.tsv`。

**理由**：本轮所有结论均基于"强信号启发式"，无真值对照。阶段一预计改判 164 题、△非课标从 74 涨到 112，缺少基准无法量化净收益。

### 阶段一（推荐，高置信，0 新增未分类）：新增 3 条优先级规则

沿用 `classify.py` 现有"立体优先 / 复数优先 / 统计优先"的同一套写法，插在其后：

| 规则 | 触发条件 | 提升目标 | 改判 |
|------|---------|---------|-----:|
| **R1 圆锥曲线优先** | 含 `椭圆`/`双曲线`/`抛物线`/`焦点`/`离心率`/`渐近线`/`准线`/`圆锥曲线`，**且不含** 复数语境（`复数`/`虚数`/`复平面`/`共轭`/`实部`/`虚部`/`虚根`） | `conic` | 127 |
| **R2 概率优先** | 含 `概率`/`分布列`/`随机变量`/`古典概型`/`互斥`/`独立事件`/`正态分布`/`二项分布`，且当前 primary ∈ {counting, set, vector2d, inequality, logic} | `prob` | 33 |
| **R3 非课标优先** | 含 `矩阵`/`行列式`（→matrix）、`参数方程`/`极坐标`（→parametric）、`定积分`/`不定积分`/`微积分`（→calc_adv）、`程序框图`/`算法`/`框图`（→algorithm）；**不含 `极限`** | 对应非课标单元 | 38 |

规则顺序：`统计优先` > `概率优先` > `非课标优先` > `圆锥曲线优先` > `复数优先`。

**预期分布变化（模拟值）**：

```
单元   conic   111 → 233  (+122)      line_circle  116 →  67  (-49)
       prob     41 →  74  (+33)       vector2d     135 → 105  (-30)
   parametric   16 →  38  (+22)       trig         326 → 303  (-23)
      matrix     9 →  24  (+15)       inequality   237 → 211  (-26)
                                      counting     134 → 112  (-22)
                                      set/logic/seq/solid_basic 小幅下降

主题   几何与代数 762 → 830 (+68)      概率与统计   194 → 205 (+11)
       预备知识   479 → 432 (-47)      函数         807 → 775 (-32)
       数学建模     19 →  19 ( 0)

△非课标：74 题 → 112 题
未分类：0 → 0
```

### 阶段二（关键词收窄）：空间向量降级

`space_vec` 的 `距离`/`夹角` 改为**不作为 primary 依据**（仅当其他单元均无命中时才生效）。约 26 题改判，16 题 → 直线与圆。

**副作用与补救**：产生 4 道新的未分类题，已定位，需补窄关键词：

| 题 | 内容 | 应归 |
|---|---|---|
| 2011 上海文#8 / 2011 上海理#6 | $\angle CAB=75^\circ$、$\angle CBA=60^\circ$，求 $AC$ 距离 | trig |
| 2014 上海春#11 | 货船看灯塔北偏东 $30^\circ$→$75^\circ$，求距离 | trig |
| 2018 上海春#6 | 动点到 $(1,0)$、$(-1,0)$ 距离之和等于 4，求轨迹 | conic |

### 阶段三（风险较高，须在阶段 0 之后）

1. **`inequality` 让位规则**：无强信号时让给有强信号的单元（潜在 ~140 题，最大的一块）。须逐类确认"最大值/最小值"类题目到底该归谁，**不可直接删关键词**（会产生 22 道未分类）。
2. **`logic` 精细化**：保留 `充要`/`充分`/`必要`，让"下列命题中正确"类套话失效（21~28 题，去向有好有坏）。
3. **选项噪声治理**：只在 `\choices` 前正文计分。模拟 114 题改判，但**存在明确反效果**——`\cap`（平面交线）与 `属于区间` 会被 `set` 误吞（如 2001 上海春#15、2010 上海理#17），故**不推荐整体采用**，仅在阶段 0 确认后对个别词加否证。
